# uc4-aula4-15-10-26

Instruções
Atividade 1 — Número aleatório
Crie um programa PHP que gere um número aleatório entre 1 e 100 e mostre na tela o número sorteado.

Requisitos:

Utilize a função rand().

Exiba o resultado utilizando echo.

Atividade 2 — Calculando a raiz quadrada
Crie um programa PHP que armazene o número 144 em uma variável e calcule sua raiz quadrada.

Requisitos:

Utilize a função sqrt().

Exiba o número original e sua raiz quadrada.

Atividade 3 — Potenciação
Crie um programa PHP que calcule o resultado de um número elevado a uma potência.

Requisitos:

Armazene o número 5 em uma variável.

Armazene o expoente 3 em outra variável.

Utilize a função pow() para calcular a potência.

Exiba o resultado na tela.

Atividade 4 — Constante de informações
Crie um programa PHP que declare constantes para armazenar o nome de uma escola e o ano atual.

Requisitos:

Crie a constante ESCOLA com o nome de uma escola.

Crie a constante ANO com o ano de 2026.

Exiba uma mensagem utilizando as duas constantes.

Atividade 5 — Aprovado ou reprovado?
Crie um programa PHP que sorteie duas notas entre 0 e 10, calcule a média e informe se o aluno foi aprovado ou reprovado.

Requisitos:

Utilize rand() para gerar duas notas inteiras entre 0 e 10.

Calcule a média das duas notas.

Utilize if/else para verificar o resultado.

Considere que o aluno está aprovado se a média for maior ou igual a 7. Caso contrário, estará reprovado.
